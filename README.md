# exview-data

엑뷰(ExView) 크롬 확장 프로그램이 사용하는 **엑셀 채널 명단**입니다.

## channels.json

확장 프로그램이 지켜보는 유튜브 채널 목록입니다.
채널이 새로 생기거나 사라지면 이 파일만 고치면 됩니다.
스토어 심사 없이 **약 5~15분 안에** 모든 사용자에게 반영됩니다.

### 항목 설명

| 항목 | 설명 |
|---|---|
| `id` | 채널을 구분하는 값. 영문·숫자·`_`·`-` 만 |
| `name` | 화면에 보이는 이름 |
| `handle` | `@핸들` 또는 `UC...` 채널 ID |
| `order` | 정렬 순서 |
| `avatarUrl` | 프로필 사진. `yt3.googleusercontent.com` 또는 `yt3.ggpht.com` 만 |

### 고칠 때 주의할 점

확장 프로그램이 받아온 뒤 **검사를 거칩니다.** 아래를 어기면 이 파일 전체가 무시되고
확장에 내장된 예전 목록이 쓰입니다.

- 채널 수는 **10개 이상 200개 이하**
- `handle` 에 공백, `/`, `?`, `#`, 따옴표가 들어가면 안 됨
- `avatarUrl` 이 유튜브 주소가 아니면 그 값만 버려짐 (채널은 유지)
- 쉼표나 괄호가 빠지면 JSON 이 깨져서 전체가 무시됨

고친 뒤 형식이 맞는지 확인하고 저장하시면 안전합니다.
